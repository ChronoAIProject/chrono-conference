# 第二章 发动机人人可买，我们造的是整车

走进一间赛车维修间，把一台五百马力的裸发动机直接放在潮湿的水泥地上踩油门——你不会拿到一圈赛道成绩。你会拿到一阵撕裂耳膜的尖叫、满地滚烫的机油，以及一个没有飞轮也没有刹车、随时要把墙撞穿的铁疙瘩。

今天大多数关于「AI 落地」的讨论，本质上都是一群人蹲在湿水泥地上，对着一台裸发动机发愁。

过去两年，全球顶尖实验室把几乎全部算力押在了把发动机越造越猛上。结果既美妙又冷酷：**强推理发动机成了按次计费、人人随买随租的公开水电。** 你花几美分就能租到一流马力，你的对手三分钟后也能租到一模一样的一台。真正决定你能不能载着真实客户与真金白银平安跑完高速的，从来不是把裸发动机绑在滑板上，而是**底盘、防爆油箱、方向盘、刹车与安全带**——一辆明天你可以整颗换掉发动机、却一秒都不熄火的**整车**。

::: {.remark #rem-ch02-vehicle-analogy title="结构类比：发动机、门卡与整车"}
「裸发动机 vs. 整车」以及下文将 `NyxID` 比作「限时酒店房卡」均属于工程类比 **（类比）**，用来直观拆解推理模型与智能体基础设施的分工边界；它们是建筑比喻，不是数学定理。
:::

## 裸发动机为什么上不了真实公路

把「裸接模型」和「五层整车」并排切开放在同一张剖面图上，差别连一句废话都不需要。左边把明文 API 密钥直接塞进环境变量，把业务流程写成一段随时会漂移的长提示词，没有任何写操作刹车——只要外部网页里藏一句恶意提示注入，整套脚本连带着你的钱包一起冲下悬崖。右边把推理核放进可热插拔的机舱，所有碰触现实世界的危险动作，必须逐层穿过五道冷冰冰的硬边界。

::: {.figure src="ch02-engine-vs-vehicle"}
**裸发动机与五层整车剖面对比。** 左栏为无护栏的裸接智能体（明文密钥暴露在上下文、提示词漂移、无审计回滚）；右栏为 ChronoAI 五层整车架构，推理引擎可随时热替换，所有凭证、技能、沙箱与判官约束由底盘统一承载。
:::

这五层底盘不是白板上的愿望清单，而是每周在仓库群里承受数千次提交与真实调用的在役铁件。像拆解一枚机械表一样，从底层到前台逐层打开（全部口径核验截至 2026 年 11 月 27–28 日）：

1. **第一层：身份与零密钥底座（`NyxID` `v0.78.0` 与 `nyx-assistant-sdk v0.2.4`）**
   酒店经理绝不把总钥匙交给代客泊车，而是只发一张**限时、仅开 412 号房、中午作废的磁卡** **（类比）**——总钥匙永远锁在加密代理金库里，**`0` 比特明文密钥进入智能体上下文**。线上生产版 `api.nyxid.ai` 运行 `v0.78.0`，免邀请注册、`1 credit = 1 USD` 并支持 BYOK，原生接通 **55 项内置服务**、**42 份 OpenAPI→MCP 规范**、**7 家 LLM 网关**与 **9 类生产消息渠道**（`dev 0.79.0` 已扩至 **11 类**，新增 Meta Messenger 与 Instagram）；刚发布的 **`nyx-assistant-sdk v0.2.4`** 已直接驱动 `live.trureturing.org` 上的实时语音向导 Alexandra。精确提交哈希、适配器清单与 `NyxBot` 触发限额见第二卷（`CHRONO//STACK`）与本卷附录 B。
2. **第二层：技能生命周期 API（`Ornn` `v0.18.0` Alpha 与 `nyx-skills`）**
   把智能体工作流从聊天框里随时漂移的咒语，收编成带版本号、经 AgentSeal 扫描并绑定 `NyxID` 权限作用域的标准软件零件。`Ornn` 开放 **134 个 OpenAPI 操作端点**、**18.7 万行源码**与 **286 份测试文件**，支撑公共目录 `nyx-skills` 中的 **163 项公开技能**跨全网直接复用；SDK 版本、路径分布与源码提交见第二卷（`CHRONO//STACK`）与附录 B。
3. **第三层：云端托管与本地编排双引擎（`CMA` `v0.12.0` 与 `heca`）**
   同一副底盘配两套驾驶舱：云端托管 **CMA** 已以 **`Apache-2.0`** 协议开源 `v0.12.0`，用两大核心服务与 Kubernetes 沙箱支撑约 **2.1 秒**的热凭证重载；本地优先编排器 **heca** 则把 **27 类智能体**摆上空间画布，为每个执行体隔离独立 Git 工作树、终端与浏览器，已连续沉淀 **360 个夜间构建**。完整运行时矩阵与构建标签见第二卷（`CHRONO//STACK`）与附录 B。
4. **第四层：可执行判官与协作治理（`chrono-harness` 与 `sshx`）**
   不再用客气提示词求智能体「请务必跑完测试」，而是用声明式 `FILEMAP` 依赖边与 `DELTA` 增量判官立下冷硬绊线：触及哪条边就强制测哪条边，漏登文件当场拒收。活跃开源主家 **[`chrono-harness`](https://github.com/chrono-harness/)** 汇集 **25 个公开仓库**（组件发版横跨 **`v0.1.3`–`v0.1.22`**，核心执行器 `chrono-harness-runner v0.1.22`；估算 **27.6 万行** Rust、双平台各 **21 个预编译二进制**、Copier **`v0.1.52`**、**29 条原子规则**），配合 `MIT` 协议的 `sshx`（`v1.0.0-beta.58`）把多视角独立审稿焊进交付流。详细分仓目录与验证边界见第二卷（`CHRONO//STACK`）与附录 B。
5. **第五层：真实业务与科研表面（`chrono-metaverse`、`chrono-cd`、`Living with AI`、`trureturing`）**
   车不是造来盖绒布吃灰的：同一副底盘同时驱动 `street-corner` 三维会场与从办公室机柜屏一路拉升至地球轨道 `5,307 km` 银幕的四级延伸转播管线、私有零运维部署底座 `chrono-cd`、通向真实房间的 `Living with AI`（`nyx-homeassistant-node` 与 `Apache-2.0` 硬件面板 `nyxid-esp-panel v1.0.0`），以及独立科研品牌 **The Omega Institute** 旗下在 Lean 4 内核上全天候掘进的 `trureturing`。精确版本与硬件配置见第二卷（`CHRONO//STACK`）与附录 B。

## 亲手验证：四个把裸原型当场撞散的关键工况

别听纸上谈兵，坐进驾驶座，用交互示意实验台 `VEHICLE//STACK` 亲自拉动四个最容易把普通 AI 原型瞬间撞散的工况。

第一个工况叫**热换发动机**。任务跑到一半，上游突然换代或限流，你把机舱里的推理核从 `Engine Alpha` 瞬间切到 `Engine Beta` 或本地核心。在散装脚本里，换缸等于重登凭证、重绑工具、丢光会话；在整车架构里，身份、技能、刹车与判官全部沉在底盘上，换缸后整条任务流不断线、不重鉴权、零状态丢失。

::: {.viz src="engine-vehicle-stack" preset="swap" height="500"}
**热换发动机（`swap`）。** 机舱在任务执行中段将推理核由 `Engine Alpha` 热切换至 `Engine Beta`；下方青色底盘总线（`NyxID`、`Ornn`、`CMA / heca`、`chrono-harness`）保持连续贯通，上下文泄露密钥数始终为 `0`。
:::

第二个工况叫**零明文金库**。盯紧 `NyxID` 那条硬线：穿过机舱的永远是一张窄作用域的不透明能力句柄。真正的 OAuth 令牌与 API 密钥只在代理内存中完成注入，并在响应回传给模型前彻底清洗。哪怕外部网页藏着恶毒的提示注入，机舱里压根没有明文钥匙可供偷走。

::: {.viz src="engine-vehicle-stack" preset="vault" height="500"}
**凭证不进上下文（`vault`）。** 数据包跨越 `NyxID` 边界时，模型侧仅可见窄作用域能力句柄，明文密钥在金库内完成注入与清洗，`plaintext_in_context` 恒定保持 `0`。
:::

第三个工况是把**玩具**与**员工**一刀切开的分水岭：**写操作人工闸门**。查账本、读仓库、看座位余量，可以放心交给智能体全天候自动值守；但数据包只要碰触会改变外部世界的写操作——划转资金、发布未审核声明、删除生产资源——系统就在琥珀色闸门前硬性刹车，等人类明确签批再放行。

::: {.viz src="engine-vehicle-stack" preset="approval" height="500"}
**写操作人工闸门（`approval`）。** 只读查询沿青色通道自动放行；涉及外部状态变更的写请求在琥珀色人工审批闸门前挂起等待授权，确保不越权执行。
:::

第四个工况最能试出架构底色：**一键紧急吊销**。一旦云端托管会话出现异常，管理员在 `NyxID` 撤回授权；运行在 `CMA` 沙箱中的代理无需重启容器，也无需紧急轮换上游全部主密钥，在 `CMA` 实测约 **2.1 秒**的热重载窗口内即可刷新凭证态，示意下游调用随即转为 `403 REVOKED` 硬拦截，当场止血。

::: {.viz src="engine-vehicle-stack" preset="revoke" height="500"}
**一键热吊销（`revoke`）。** 演示在 `NyxID` 撤回会话授权后，`CMA` 云端运行时在约 2.1 秒热重载窗口内完成权限收敛、示意调用转为 `403 REVOKED` 拦截状态，无需重启运行中沙箱。
:::

## 把还没拧紧的螺丝也摊在工作台上

整车主义从来不是完美主义。把半成品刷成亮漆冒充完全体，那和第一章嘲笑的淘金热毫无二致。我们把今天尚未拧紧的每一颗螺丝明码标在这里（完整核验矩阵见第二卷《整车工程》附录 B）：

- **`heca` 源码仍为私有 / 内部状态**：它已在内部连续跑出 **360 个**夜间构建（最新 `0.1.0-nightly-20261121-1`）、每天撑起高密度多智能体研发，但源码仓尚未对外公开（且 Apple `container` 运行时仍受阻）。
- **`CMA` 今天仍聚焦单一主编码运行时**：`v0.12.0` 已在 `Apache-2.0` 下开放且热凭证重载已上线，但多运行时全面铺开仍在演进队列中。
- **`chrono-harness` 活体组件仍硬编码 `completeness_proven: false`**：`21` 个预编译二进制和 `DELTA` 增量判官已在日常仓库强制服役，但规范与活体 crate（`runner`、`inputs`、`judge-*`、`cache`）诚实标明形式完备性尚未证明；独立新组织下各仓的根目录 `LICENSE` 文件也在补齐中（派生说明遵循 `Apache-2.0`，`sshx` 为 `MIT`）。
- **`chrono-cd` 保持私有，`Living with AI` 家庭节点仍属 Alpha 硬件验证**：我们绝不把内部工具或硬件原型包装成已规模量产的商品。

把上面四个工况收束进同一块工作台，下面的完整交互示意实验室 `VEHICLE//STACK` 允许你自由组合引擎插槽、审批策略与紧急吊销开关，亲手把整条总线的零密钥不变量来回拨弄一遍。

::: {.viz src="engine-vehicle-stack" height="560"}
**完整交互示意实验室：`VEHICLE//STACK`。** 自由切换机舱推理引擎、读写审批策略与吊销开关，沿时间轴追踪示意工具调用穿过五层整车架构的生命周期与零密钥不变量。
:::

造出一辆稳当的整车只是上半场。当一家组织同时运转几十个智能体、上百项技能、数十个服务与数百个仓库，如果每辆车各修各的土路，系统很快就会重新碎回泥潭。下一章我们退后一步俯瞰全局：为什么 ChronoAI 宁可啃最硬的骨头，也要把全套基础设施织成**一张网**，把 AI 狂飙里的「红皇后赛跑」驯成一只只进不退的棘轮。
