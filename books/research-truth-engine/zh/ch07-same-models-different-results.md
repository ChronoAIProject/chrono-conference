# 第七章 同样的模型，不同的结果：开放科研操作系统与未解边界

每当我们在学术讨论或直播演示里摊开 `trureturing` 的实测总账——截至 2026 年 11 月 27 日（`548388cd`）累计 **223,231 条**冻结 Lean 4 定理（七天净增 `+33%`）、自 `2026-09-08` 至 `2026-11-27` 连续 **`81` 天**解决 **`2,278` 道**公开文献开放题（`2,276` 道带日期 + `2` 道未标日期：`1,512` 证 / `766` 反，日均约 `28` 道）、连续 **`720 / 720`** 个 UTC 小时每小时都有提交（中位数 `63` 提交/时、`217` 合并 PR/天）——几乎每一间屋子抛出的第一个问题都一字不差：

**「你们是不是暗藏了一颗别人买不到的秘密大模型？」**

没有。不仅没有，事实恰恰相反：**驱动这套系统的底层推理引擎，市面上每个人都能按次付费买到。**

那么，不妨换一幅物理实验台上的画面**（类比）**：把一枚磨得锋利无比的显微镜物镜悬在半空、却不给它配一只厚重的黄铜光学台座，地板稍有微震，拍出来的每一张底片都会抖成一团模糊重影。把同一套商用推理引擎丢进普通对话框，吐出来的正是这种似是而非的「伪证明」和第三步就偷换概念的「显然可得」；而把它们锁进 `trureturing` 的光学台座之后，却化作一台连续 `720` 个 UTC 小时不掉链子、在 `81` 天里日均凿出二十八道可供 Lean 4 内核当场验尸的逻辑棘轮。

沿着这同一则实验台**（类比）**，答案落回整场发布会反复敲打的那一颗钢钉：**决定科学成像清晰度的从来不只是单次对话里那枚裸物镜，而是焊在它外面的整套「科研操作系统」——刚性台座、精密微调、不可逆真值图、可执行反例闸门，以及零容忍的编译器内核。**

## 把「单次聊天」锻造成「科研操作系统」的四根支柱

用实验物理学家的眼睛把 `trureturing` 和普通聊天框并排拆开，你能一眼摸到四根少一根就散架的承重钢梁：

1. **把记忆从易失对话框搬进不可逆真值图**：关掉聊天窗口，失忆立刻把黑板擦得一干二净；`trureturing` 把每一条通过内核校验的引理冻结进 `Golden/Frozen/state/`，让 **`17,968` 个冻结模块、`20,223` 份 `.lean` 文件、`602 万`行代码**变成后续每一次攻关可直接 `import` 的钢筋地基。
2. **用形式化信息逃逸判据与独立去重审计封死原地刷数**：正如第二章的 [@thm-ie-recoverable] 与 [@thm-ie-same-kernel] 所锁定的有限集合判据，系统在数学上把「真正切开盲区的新发现」和「换皮复述旧结论」劈成两半，再以仓库级自动化去重与账本审计把这条纪律钉进日常合并。
3. **把高并发探索锁进隔离工作树与硬门禁**：
   - `heca` 为并行研究代理分配隔离 Git 工作树；
   - `chrono-harness`（活跃托管于 `https://github.com/chrono-harness/`，含 `25` 个公开组件仓，同时诚实保留活体 crate 中硬编码的 `completeness_proven: false`）执行声明式增量判官；
   - 托管于 `the-omega-institute/trureturing-tools` 的 **`StrataLint` `23` 条现役静态规则**（登记 `27` 条、`4` 条延后）死守公理与规范边界。正因三道铁栅栏彼此咬合，每小时中位数 `63` 次提交与日均 `217` 个合并 PR 才不会撞碎或偷渡未申报公理。
4. **把全球学者与开源社区变成最苛刻的现实校准**：
   - 早期 `automath` 基线（2026-08-04 统计 `49,623` 条声明、`18,624` 条定理、`7,877 / 12,989` 条陈述匹配率 `60.6%`）先摸清了自然语言转译的真实摩擦；

## 用对照实验拆开引擎盖：`human-in-the-loop-automated-research v1.0`

口说无凭，把「操作系统的增益」拉上真正的对照实验台。`mathesis-papers` 于 `2026-11-27` 公开的方法论论文 **`human-in-the-loop-automated-research v1.0`**（提交 `812c64de9e`）直接把当今 AI 科研的病理切成四块，并端出了完整的实测账单。

先把病灶叫准。裸跑的自动化系统不会只犯一种错，它会同时制造两类对称的灾难，再衍生出两层更隐蔽的毒素：

- **科学垃圾（scientific slop）**：全自动流水线一口气吐出修辞流畅、图表精致、推导却在关键引理处悄悄断裂的伪论文；
- **证明消化不良（proof indigestion）**：人类同行被海量未经筛选、真假掺杂的机器证明稿淹没，核验成本反超人类自己动笔；
- **形式化注水（formal slop）与审稿注水（review slop）**：前者靠堆砌平凡引理或偏离原意的弱陈述刷绿编译器，后者则是多个前沿模型在散文审稿里犯下高度相关的假阳性拍手错误——哪怕换了不同模型家族互审，也会一起把坏证明放过关。

为了把这四层病理测出硬数字，该手稿给出了四组可复核实证（全部评审均严格在**三个独立前沿模型家族**间盲测完成）：

| 实证维度 | 核心设计 | 关键实测读数 |
| --- | --- | --- |
| **$N = 30$ 三家族盲评基准** | 三类论文各 `10` 篇（人机协同、未验证人类预印本、全自动 AI），由**三个独立前沿模型家族**盲评，共 `90` 次评审（评委一致性 Kendall $W = 0.828$） | 人机协同在成对比较中以 **`260 / 300`（`86.7%`）** 击败全自动 AI（各家族检验 $p = 0.0012,\; 0.0149,\; 3.2\times 10^{-5}$）；较未验证人类预印本将评分标准差压缩 **`2.3–4.2` 倍**（直接削掉致命错误长尾）；**`10 / 10`** 具形式化或核验支撑（对比人类 `1 / 10`、全自动 AI `0 / 10`；定理块数量 **`165` vs `119` vs `1`**） |
| **`20` 命题机理消融** | 比较单家族散文审稿、**跨模型家族冷审**共识与加入**可执行反例义务闸门**后的真伪判别 | 即便**跨模型家族冷审**达成散文共识，仍残留 **`20%`** 的相关假阳性「审稿注水」；一旦焊上**可执行反例义务闸门**，假阳性率直接从 **`30%` 跌至 `0.0%`**，达到 **`100%` 精度、`94.7%` F1、`95.0%` 准确率**（Fisher 精确检验 $p = 0.000119$） |
| **`24,925`-PR 准入闸门审计** | 回溯全库 `24,925` 个 PR 的准入拦截与近 `1,000` 个已合并 PR 的修复轨迹 | **`8.0%`**（`1,995` 个）在准入前即被未合并关闭；最近 `1,000` 个已合并 PR 中，有 **`59.6%`**（`557 / 935`）必须在自动化门禁逼迫下历经多轮提交修复才过关（中位修复耗时 **`31.9` 分钟**） |
| **`33` 小时全量埋点轨迹** | 精确记录连续 `33` 小时人机协同攻坚中的人类输入密度与系统产出 | 人类架构师仅发出 **`31` 条简短指令**（总计约 **`1,730` 个中文字符**），便定向驾驭 **`6` 个 Lean 4 单元**落地，并在中途硬性保留下 **`52` 条早期反驳**，防止引擎在死胡同里继续堆词 |

盯紧第二行和第三行，你会听见整座铁砧清脆的回响：

- **散文投票挡不住相关错误。** 就算拉来**三个独立前沿模型家族**背靠背打冷审，只要裁判武器还是自然语言，仍然会有五分之一的坏命题靠「听起来很顺」滑过防线；唯有把举证责任焊成**可执行反例义务闸门**（让代码与编译器替你验尸），假阳性才会一刀归零（`30% → 0.0%`）。
- **门禁不是装饰品，它每天都在真实拦截。** 将近六成最终合入主线的 PR，第一次提交根本过不了关——全靠机械闸门逼出多提交修复，才守住了 `548388cd` 零 `sorry`、零偷渡公理的防线。
- **人类扮演的不是苦力，而是舵手。** 三十三小时里不到两千字的 `31` 条关键判断，就把方向盘稳稳锁在有价值的航线上，把 `52` 次早期证伪变成避免白费算力的宝贵护栏。

照旧，把这篇方法论手稿自己写死在讨论节里的**四项局限**原样摊在桌上，一字不减：

1. **缺乏线上随机无门禁对照组**：生产科研仓库不能为了做 A/B 实验故意放任坏证明污染主线，因此准入审计属于真实生产观测，而非随机双盲实验；
2. **全自动基准的文体并不完全等同**：对比组中的全自动 AI 论文来自公开外部基准，其任务形态与前沿文献开放题存在体裁差异；
3. **单篇评审受限于 `36k` 字符窗口**：盲评读取上限为每篇 `36k` 字符，超长附录与外部代码树并未整包塞入盲评上下文；
4. **消融集中存在一例真实漏判（`ab_17`）**：在 `20` 项命题消融里，闸门曾出现 `1` 例类型层面的漏判（`ab_17`），原样留档供后来者复现与改进。
