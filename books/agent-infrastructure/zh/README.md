## 本卷五层解剖图

全书七章加两份工程总账附录，逐一对应整车从底层身份到物理世界边缘的每一层：

1. **第一章 `NyxID`（`v0.78.0`）**：零密钥代理边界、55 项内置服务、41 份 OpenAPI→MCP 规范、7 家 LLM 网关、9 类消息渠道与 `1 credit = 1 USD` 计量底座。
2. **第二章 `NyxBot`、`NyxAgent` 与浏览器助手 SDK**：8 默认 / 32 上限专项代理网格、50 条受控记忆槽、每小时 30 / 每日 300 触发器防失控闸门。
3. **第三章 `Ornn`（`v0.18.0`）与 `nyx-skills`**：134 个 OpenAPI 操作端点（109 条路径）、18.7 万行代码、286 份测试文件与 163 项公开技能的完整软件化生命周期。
4. **第四章 `CMA` 与 `cmaeg`**：云端托管智能体四层架构、事件网关与约 `2.1 s` 凭证热重载（并如实标明当前单一主编码运行时状态）。
5. **第五章 `heca`**：面向深度构建者的本地优先画布编排器（6 主供应方 + 21 ACP = 27 类智能体、361 个夜间构建，如实标明源码待公开）。
6. **第六章 `chrono-harness`（`v0.1.4`）与 `sshx`（`v1.0.0-beta.58`）**：27.2 万行 Rust、25 个模块化仓与 16 个二进制工具如何用 `FILEMAP` 与 `DELTA` 增量判官替代一厢情愿的提示词。
7. **第七章 屏幕之外**：三维空间 `chrono-metaverse`、零运维部署 `chrono-cd` 与通向真实家庭的 `Living with AI`（`nyx-homeassistant-node v1.1.1-alpha.52`）。
8. **附录 A 与附录 B**：全企业代码仓库全景地图，以及不遮掩任何半成品边界的**诚实成熟度矩阵**。
