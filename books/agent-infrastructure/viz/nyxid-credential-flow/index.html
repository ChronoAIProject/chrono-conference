理论接口 · 这个页面在演示什么Theory interface · what this page shows

同一次调用、同一条带毒的工具响应，同时走两条通道。上方是传统直连：k 项服务的明文密钥放在智能体的环境变量里；下方是 NyxID 的四层零密钥代理：智能体只持有一个受限能力句柄，真正的令牌封存在代理金库里，在请求离开边界前注入、在响应回传前洗掉。本页是示意模型与数值演示，不是证明，也不是生产系统的抓包。

  1. 泄露面。“智能体能读到的明文密钥”在直连通道里就是 k：一次成功的提示注入能把它们全部带走，所以泄露面随 k 线性增长。NyxID 一侧智能体的上下文里没有明文密钥，这个数对每个 k、每种工况都是 0。拖动 k（1 到 55），上方的钥匙格随之增减，下方智能体框里始终是空的。
  2. 作用域。能力令牌只允许 read:issues：读取放行，越权写入与注入后发往攻击者的横向外联都在策略引擎处被拒绝，每一次放行或拒绝都记进审计账本。
  3. 热重载。在 NyxID 里吊销一项绑定后，运行中的沙箱在约 2.1 s 内收敛到新绑定，不重启；之后的调用返回 403 REVOKED。直连通道要轮换上游密钥并重新部署，进程会重启一次。2.1 s 是第四章给出的 CMA 口径，页面按这个时长画。
  4. 计量。每次代理调用按示例单价 0.25 credit 计量，1 credit = 1 USD；单代理封顶为示例值 4 credit，到顶后后续调用在代理处硬停。BYOK 模式下花费记在你自己的上游密钥上、不扣 credit，封顶仍然生效。示例单价与封顶不是 ChronoAI 的实际价格。

书中：第一章 · NyxID：零密钥连接与身份底座 · 第四章 · CMA 与约 2.1 s 的凭证热重载

The same call and the same poisoned tool response travel two lanes at once. Above is legacy wiring: plaintext keys for k services sit in the agent's environment. Below is NyxID's four-layer zero-secret proxy: the agent holds one scoped capability handle, and the real tokens stay sealed in the proxy vault, injected just before a request leaves the boundary and scrubbed before the response comes back. The page is a schematic model and a numerical illustration, not a proof, and not a capture of the production system.

  1. Blast radius. "Plaintext secrets the agent can read" is k in the legacy lane: one successful prompt injection can carry all of them away, so the blast radius grows linearly with k. On the NyxID side there is no plaintext secret in the agent's context, and the number is 0 for every k and every scenario. Drag k from 1 to 55: the key grid above grows and shrinks, the agent box below stays empty.
  2. Scope. The capability token allows read:issues only: a read passes, while an out-of-scope write and the lateral call to the attacker after the injection are refused at the policy engine, and every pass and refusal is written to the audit ledger.
  3. Hot reload. After a binding is revoked in NyxID, the running sandbox converges to the new binding in about 2.1 s without a restart; later calls get 403 REVOKED. The legacy lane has to rotate the upstream key and redeploy, which restarts the process once. The 2.1 s is the figure chapter 4 gives for CMA, and the page draws that duration.
  4. Metering. Each proxied call is metered at an example price of 0.25 credit, with 1 credit = 1 USD; the per-agent ceiling is an example value of 4 credits, after which further calls stop hard at the proxy. In BYOK mode the spend is billed to your own upstream key and no credits are debited, and the ceiling still applies. The example price and ceiling are not ChronoAI's actual prices.
